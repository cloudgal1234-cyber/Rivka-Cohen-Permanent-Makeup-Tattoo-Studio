# רבקה כהן – קעקועים בחומר של איפור קבוע | גבעת זאב

אתר תדמית בעברית (מימין לשמאל) לסטודיו של רבקה כהן – קעקועים עדינים בחומר של איפור קבוע.
סלוגן: "מקעקעים בלי פחד, כי אין פה נצח".

## עמודים
- `index.html` – האתר הראשי (כולל הוראות אחרי טיפול וציר ההחלמה).
- `forms.html` – הצהרת בריאות וטופס הסכמה לטיפול. המטופלת ממלאת, ואז שולחת לרבקה בוואטסאפ או מדפיסה / שומרת כ-PDF. שום מידע לא נשמר בשרת.

## איך לצפות
לפתוח את `index.html` בדפדפן. אין צורך בהתקנה.

## לוגו וצבעים
- `assets/logo-full.png` – הלוגו המלא עם הסלוגן (בתחתית העמוד).
- `assets/logo.png` – סימן ה-RC בלבד (בכותרת ובחלק "אודות").
- צבעי האתר לקוחים מהלוגו: שחור, ורוד עתיק וורוד בהיר. הם מוגדרים בתחילת `css/style.css`.

## תמונות
בגלריה יש תמונות השראה חינמיות מ-Pexels (עם איור קו דק כגיבוי אם תמונה לא נטענת). מומלץ להחליף אותן בתמונות של עבודות אמיתיות של רבקה.
