# רבקה כהן – קעקועים בחומר של איפור קבוע | גבעת זאב

אתר תדמית בעברית (מימין לשמאל) לסטודיו של רבקה כהן – קעקועים עדינים בחומר של איפור קבוע.
סלוגן: "מקעקעים בלי פחד, כי אין פה נצח".

## עמודים
- `index.html` – האתר הראשי (כולל הוראות אחרי טיפול וציר ההחלמה).
- `forms.html` – גרסה להדפסה של הצהרת הבריאות וטופס ההסכמה (אפשר גם לשלוח בוואטסאפ).

## מערכת תורים וניהול
- `book.html` – קביעת תור אונליין: בחירת קעקוע, תאריך ושעה פנויים, פרטים, ולקוחה חדשה ממלאת הצהרת בריאות וטופס הסכמה עם חתימה. יש גם הרשמה לרשימת המתנה.
  - `book.html?health=1` – מילוי הצהרת בריאות בלבד (קישור שרבקה שולחת ללקוחה שנקבעה ידנית).
- `admin.html` – דף הניהול של רבקה (שם משתמש + סיסמה):
  - יומן שבועי, אישור / הזזה / ביטול / סימון הגעה, הערות פנימיות, הוספת תור ידני.
  - אחרי כל שינוי – כפתור לשליחת עדכון ללקוחה בוואטסאפ, וכשתור מתפנה מוצגות הממתינות שמתאימות לאותו יום.
  - כרטיס לקוחה: טלפון, ת״ז, הצהרת הבריאות המלאה, חתימה, היסטוריית תורים, הדפסה.
  - הגדרות: שעות פתיחה לכל יום (כולל הפסקות), ימים/שעות חסומים, מרווח בין תורים, כמה זמן מראש, אישור אוטומטי, סוגי טיפולים ומשך, החלפת סיסמה.

### איך זה עובד בלי שרת
האתר כולו קבצים סטטיים. הנתונים נשמרים ב-**Firebase** של Google (תוכנית Spark – חינם, בלי כרטיס אשראי):
- `js/backend.js` – כל הלוגיקה של התורים, רצה בדפדפן מול Firestore.
- `firestore.rules` – כללי האבטחה: לקוחות יכולות רק ליצור תור / הצהרה / רישום להמתנה ולראות אילו שעות תפוסות (בלי שמות). רק רבקה קוראת ומנהלת הכול.
- `js/firebase-config.js` – פרטי החיבור לפרויקט (ציבוריים מטבעם).
- `js/vendor/firebase/` – ספריית Firebase (גרסה 12.19.0, רישיון Apache-2.0) שמורה בתוך האתר.

## הגדרה חד-פעמית (כ-15 דקות)
1. נכנסים ל-[console.firebase.google.com](https://console.firebase.google.com) ← **Create a project** (אפשר לוותר על Google Analytics).
2. **Build → Firestore Database → Create database** ← Production mode ← מיקום באירופה (למשל `eur3`).
3. בלשונית **Rules** של Firestore: מדביקים את כל התוכן של `firestore.rules` ← **Publish**.
4. **Build → Authentication → Get started** ← מפעילים **Email/Password**.
   - **Users → Add user**: מייל `rivka@rivka-cohen.studio`, וסיסמה חזקה שבוחרים (זו הסיסמה של רבקה – לא לשמור אותה בקוד!).
   - **Settings → User actions**: מבטלים את **Enable create (sign-up)** כדי שאף אחד לא יוכל לפתוח משתמש.
5. **Project settings** (גלגל השיניים) ← **Your apps** ← סמל `</>` ← רושמים אפליקציה ← מעתיקים את `apiKey`, `authDomain`, `projectId`, `appId` לקובץ `js/firebase-config.js`.
6. מעלים את האתר לאחסון סטטי חינמי, למשל **Netlify** או **Cloudflare Pages** (מחברים את המאגר ב-GitHub, בלי פקודת build, תיקיית פרסום: שורש המאגר). כל שינוי במאגר מתעדכן באתר אוטומטית.

**כניסה לניהול:** `/admin.html` · שם משתמש: `rivka` · הסיסמה שהוגדרה בשלב 4 (אפשר להחליף מתוך דף הניהול).

**חשוב:** הצהרות בריאות הן מידע רפואי רגיש. הגישה אליהן מוגנת בכללי האבטחה ובסיסמה – מומלץ סיסמה ארוכה וייחודית, ולא לשתף אותה.

## בדיקות (למפתחים)
```
npm install
npm test          # בדיקות כללי האבטחה מול האמולטור של Firebase (צריך Java)
npm run emulators # הרצה מקומית; ואז בדפדפן: localStorage.setItem('useEmulator','1')
```
