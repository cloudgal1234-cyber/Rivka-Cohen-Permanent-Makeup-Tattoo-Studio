# רבקה כהן – איפור קבוע | גבעת זאב

אתר תדמית (עמוד אחד, בעברית ומימין לשמאל) לסטודיו לאיפור קבוע ולקעקועי יופי של רבקה כהן.

## איך לצפות
לפתוח את `index.html` בדפדפן. אין צורך בהתקנה.

## הוספת הלוגו
יש לשמור את קובץ הלוגו בנתיב **`assets/logo.png`**. האתר יציג אותו אוטומטית בכותרת, בחלק "אודות" ובתחתית העמוד.
עד שהקובץ יתווסף, מוצג במקומו סמל זמני (`assets/logo.svg`).

## התאמת הצבעים לגווני הלוגו
כל צבעי האתר מוגדרים בתחילת הקובץ `css/style.css` (במשתנים `--gold`, `--nude`, `--espresso` וכו').
משנים שם, והשינוי חל על כל האתר.

## תמונות
התמונות הן תמונות אווירה מ-Unsplash, להמחשה בלבד. מומלץ להחליף אותן בתמונות עבודה אמיתיות מהאינסטגרם.
