# רבקה כהן – קעקועים בחומר של איפור קבוע | גבעת זאב

אתר תדמית בעברית (מימין לשמאל) לסטודיו של רבקה כהן – קעקועים עדינים בחומר של איפור קבוע.
סלוגן: "מקעקעים בלי פחד, כי אין פה נצח".

## עמודים
- `index.html` – האתר הראשי (כולל הוראות אחרי טיפול וציר ההחלמה).
- `server.js` – השרת: מגיש את האתר ומפעיל את מערכת התורים.
- `forms.html` – גרסה להדפסה של הצהרת הבריאות וטופס ההסכמה (אפשר גם לשלוח בוואטסאפ).

## מערכת תורים וניהול
- `book.html` – קביעת תור אונליין: בחירת קעקוע, תאריך ושעה פנויים, פרטים, ולקוחה חדשה ממלאת הצהרת בריאות וטופס הסכמה עם חתימה. יש גם הרשמה לרשימת המתנה.
  - `book.html?health=1` – מילוי הצהרת בריאות בלבד (קישור שרבקה שולחת ללקוחה שנקבעה ידנית).
- `admin.html` (או `/admin`) – דף הניהול של רבקה, מוגן בסיסמה:
  - יומן שבועי, אישור / הזזה / ביטול / סימון הגעה, הערות פנימיות, הוספת תור ידני.
  - אחרי כל שינוי – כפתור לשליחת עדכון ללקוחה בוואטסאפ, וכשתור מתפנה מוצגות הממתינות שמתאימות לאותו יום.
  - כרטיס לקוחה: טלפון, ת״ז, הצהרת הבריאות המלאה, חתימה, היסטוריית תורים, הדפסה.
  - הגדרות: שעות פתיחה לכל יום (כולל הפסקות), ימים/שעות חסומים, מרווח בין תורים, כמה זמן מראש, אישור אוטומטי, סוגי טיפולים ומשך, החלפת סיסמה.

## הרצה
צריך Node.js בגרסה 22.13 ומעלה. אין חבילות להתקנה.
```
ADMIN_PASSWORD='סיסמה-חזקה' npm start
```
האתר: http://localhost:3000 · ניהול: http://localhost:3000/admin
(בלי `ADMIN_PASSWORD` נוצרת סיסמה אקראית ומודפסת פעם אחת ביומן השרת.)

בדיקות: `npm test`

## העלאה לאינטרנט
מערכת התורים צריכה שרת Node.js עם **דיסק קבוע** (המידע נשמר בקובץ `data/studio.db`). אחסון סטטי בלבד (GitHub Pages) או Vercel לא מתאימים לחלק הזה.
מתאים למשל: Render (עם Persistent Disk), Railway (עם Volume), Fly.io (עם Volume) או שרת VPS.

משתני סביבה:
| משתנה | מה זה |
|---|---|
| `ADMIN_PASSWORD` | סיסמת הניהול הראשונית (אחר כך אפשר להחליף בדף הניהול) |
| `DATA_DIR` | תיקייה על הדיסק הקבוע, למשל `/data` |
| `TRUST_PROXY=1` | כשהשרת יושב מאחורי פרוקסי של שירות האחסון (כמעט תמיד) |
| `PORT` | נקבע לרוב אוטומטית ע״י שירות האחסון |

**חשוב:** הצהרות בריאות הן מידע רפואי רגיש – חובה להפעיל HTTPS (כל השירותים למעלה עושים זאת אוטומטית), לבחור סיסמה חזקה, ולגבות מדי פעם את הקובץ `studio.db`.
